# Statistiche di GrixisMC

`stats.json` contiene le classifiche e lo staff mostrati su https://grixismc.com.

Il file viene aggiornato **da solo dal server Minecraft** (plugin GrixisMC) mentre è acceso:
al massimo ogni 10 minuti, solo se qualcosa è cambiato, e un'ultima volta allo spegnimento.
Non va modificato a mano.

La chiave che il server usa per scrivere qui può modificare **solo questa repository**.
